          Exit

          Exit & Resignation Analytics — Data not available

          The Employee_Master sheet has no Exit Date, Resignation Date, or Last Working Date column. STATUS = INACTIVE marks that someone left, but not when — so exit trends, monthly/quarterly/yearly exits, and department-wise exits can't be calculated without guessing. Add a dated exit field to the sheet and this tab will populate automatically.

          Attrition

          Attrition Analytics — Data not available

          Attrition rate = exits in a period ÷ headcount at the start of that period. Both need dated exit records, which the source sheet doesn't have yet. Rather than approximate with an undated INACTIVE flag, this tab stays empty until exit dates are trackable.
